介绍如何使用 Java Flight Recorder (JFR) 进行性能分析

Java Flight Recorder (JFR) 实战速查手册

JFR 是 JVM 内置的低开销监控工具（生产环境可用，性能损耗通常 < 1%）。适用于分析 CPU 热点、内存泄漏、锁竞争等问题。

1. 快速检查环境

在开始之前，确保你的 JDK 支持 JFR（OpenJDK 8u262+ 或 JDK 11+ 已内置）。

3. 场景二：随应用启动开启

适用于难以捕捉的启动阶段问题，或在 Docker/K8s 容器中自动开启。

在 Java 启动参数 (JAVA_OPTS) 中添加：

参数解释：

  • disk=true: 数据写入磁盘缓存（避免占用过多内存）。
  • dumponexit=true: 程序崩溃或退出时自动保存文件。
  • duration=120s: 只录制启动后的前 120 秒（如果不加则一直录制）。

4. 结果分析工具

拿到 .jfr 文件后，下载到本地电脑使用以下工具打开：

  1. JDK Mission Control (JMC) (官方推荐)
    • 功能最全，支持火焰图、内存分配分析、IO 分析。
    • 下载地址：Adoptium JMC 下载
  2. IntelliJ IDEA (方便快捷)
    • 直接将 .jfr 文件拖入 IDEA 窗口即可。
    • 支持查看 CPU 火焰图和调用树。

5. 常见问题 (FAQ)

  • Q: Oracle JDK 8 老版本报错 Error: VM option 'FlightRecorder' is experimental...
    • A: 老版本 Oracle JDK 是商业收费功能，需添加启动参数：-XX:+UnlockCommercialFeatures -XX:+FlightRecorder。建议升级到 OpenJDK 8u262+ (如 Temurin, Corretto) 即可免费使用。
  • Q: 生产环境可以用吗？
    • A: 可以。JFR 是基于事件采样的，对应用性能影响极小（通常在 1% 左右），是排查线上问题的首选工具。
