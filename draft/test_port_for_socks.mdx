# 🧪 VPS 端口连通性测试 (临时监听法)

当不确定是**服务配置错**还是**端口被墙**时，用此方法进行“控制变量”测试。

## 1. 服务端操作 (VPS)

先找一个未被占用的端口（例如 `55555`），放行防火墙并模拟一个服务。

**第一步：放行端口**
```bash
sudo ufw allow 55555/tcp
```

**第二步：启动监听**
*注意：必须加上 `-p` 参数强制指定端口，否则部分系统会随机分配。*
```bash
# -l: 监听 (Listen)
# -k: 保持连接 (Keep-alive, 不会在一次连接后关闭)
# -v: 显示详细信息 (Verbose)
# -p: 指定端口 (Port)
nc -lk -v -p 55555
```
*成功标志：看到输出 `listening on [any] 55555 ...`*

---

## 2. 客户端操作 (本地电脑)

在本地终端（Mac/Linux）发起 TCP 连接探测。

```bash
# -v: 详细模式
# -z: 扫描模式 (不发送数据)
# -w 3: 设置 3 秒超时
nc -vz -w 3 <VPS_IP> 55555
```

---

## 3. 结果分析

| 客户端显示 | 服务端显示 | 结论 |
| :--- | :--- | :--- |
| `succeeded!` | `Connection from ...` | ✅ **通了**。端口可用，GFW 未封锁。 |
| `Connection refused` | 无反应 | ⚠️ **路通但门没开**。VPS 没在监听，检查 netcat 命令。 |
| `Operation timed out` | 无反应 | ❌ **不通**。防火墙未放行，或 **TCP 阻断 (被墙)**。 |

---

## 4. 测试后清理 (重要)
测试完成后，记得去 VPS 停止监听并关闭端口，防止安全隐患。

```bash
# 1. 按 Ctrl+C 停止 nc 进程
# 2. 删除防火墙规则
sudo ufw delete allow 55555/tcp
```
