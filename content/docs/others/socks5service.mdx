# Socks5 节点搭建方案笔记

## 1. 需求分析

- 目标：在 VPS 上搭建一个稳定的 Socks5 代理服务，用于转发流量到住宅 IP。
- 要求：
  - 支持认证，防止未授权访问。
  - 连接稳定，支持多用户。
  - 配置简单，易于管理。

## 2. 环境准备

- VPS：建议使用 Linux 服务器，如 Ubuntu 20.04。
- 安装必要的软件包：`curl`, `wget`, `vim` 等。

## 3. 搭建步骤

### 3.1 安装 Dante Socks5 服务器

Dante 是一个流行的开源 Socks5 服务器。

```bash
sudo apt update
sudo apt install dante-server -y
```

### 3.2 配置 Dante

编辑配置文件 `/etc/danted.conf`：

```bash
logoutput: stderr
internal: 0.0.0.0 port = 1080
external: eth0
socksmethod: username
user.notprivileged: nobody

client pass {
    from: 0.0.0.0/0 to: 0.0.0.0/0
    log: connect disconnect error
}

socks pass {
    from: 0.0.0.0/0 to: 0.0.0.0/0
    log: connect disconnect error
}
```

- `internal` 指定监听地址和端口。
- `external` 指定外网网卡名称，要用 ifconfig 确认自己的网卡
- `method` 指定认证方式，这里示例为用户名认证。

### 3.3 添加用户认证

创建一个代理用户：

```bash
sudo adduser proxyuser
sudo passwd proxyuserpd
```

### 3.4 启动并测试服务

```bash
sudo systemctl restart danted
sudo systemctl enable danted
```

测试脚本，正常返回 http 结果即可
```bash
curl -v --proxy socks5://proxyuser:proxyuserpd@vps的外网ip:1080 http://httpbin.org/ip
```



使用支持 Socks5 的客户端，输入 VPS IP、端口（1080）和认证用户信息测试连接。

## 4. 其他 Socks5 服务搭建方案

| 方案          | 优点                        | 缺点                         |
| ------------- | --------------------------- | ---------------------------- |
| Dante         | 稳定，支持认证，功能丰富    | 配置相对复杂                 |
| Shadowsocks   | 简单，支持加密              | 主要设计为代理，不完全是 Socks5 |
| 3proxy        | 轻量级，配置简单            | 功能较 Dante 简单            |
| SSH 隧道      | 简单安全，无需额外软件      | 需要 SSH 连接，性能有限       |
