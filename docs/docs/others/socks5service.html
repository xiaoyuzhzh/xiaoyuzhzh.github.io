socks5服务搭建

为了方便给住宅 ip 做前置节点，找一个 vps 搭建一个 socks5 服务

Socks5 节点搭建方案笔记

1. 需求分析

  • 目标：在 VPS 上搭建一个稳定的 Socks5 代理服务，用于转发流量到住宅 IP。
  • 要求：
    • 支持认证，防止未授权访问。
    • 连接稳定，支持多用户。
    • 配置简单，易于管理。

2. 环境准备

  • VPS：建议使用 Linux 服务器，如 Ubuntu 20.04。
  • 安装必要的软件包：curl, wget, vim 等。

3. 搭建步骤

3.1 安装 Dante Socks5 服务器

Dante 是一个流行的开源 Socks5 服务器。

3.2 配置 Dante

编辑配置文件 /etc/danted.conf：

  • internal 指定监听地址和端口。
  • external 指定外网网卡名称，要用 ifconfig 确认自己的网卡
  • method 指定认证方式，这里示例为用户名认证。

4. 其他 Socks5 服务搭建方案

方案优点缺点
Dante稳定，支持认证，功能丰富配置相对复杂
Shadowsocks简单，支持加密主要设计为代理，不完全是 Socks5
3proxy轻量级，配置简单功能较 Dante 简单
SSH 隧道简单安全，无需额外软件需要 SSH 连接，性能有限

  • 3proxy 官方网站
