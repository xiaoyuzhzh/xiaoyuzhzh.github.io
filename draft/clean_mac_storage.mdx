# Mac "系统数据" (System Data) 异常占用排查与清理指南

> **背景：** MacBook Pro 进程会因为一些未知的缓存占用磁盘，并且系统的 storage 功能并不支持找到这些并清理。
> **核心思路：** 这是一个排查 "虚胖" 的过程，重点在于定位 `~/Library` 下的开发者缓存、容器镜像和聊天软件存档。

## 1. 第一步：排查本地快照 (Time Machine)
如果是系统数据突然暴涨，首先检查是否因为 Time Machine 备份未及时从本地上传到 NAS/外接盘。

```bash
# 检查是否存在本地快照
tmutil listlocalsnapshots /

# 如果有输出（如 com.apple.TimeMachine.2025...），使用循环命令批量删除：
for d in $(tmutil listlocalsnapshots / | grep -oE '20[0-9]{2}-[0-9]{2}-[0-9]{2}-[0-9]{6}'); do sudo tmutil deletelocalsnapshots $d; done
```

---

## 2. 第二步：定位 `~/Library` 中的 "大文件"
这是开发者电脑空间丢失的重灾区。使用 `du` 命令找出大于 1GB 的文件夹。

### 2.1 总览排查
```bash
# 扫描 Library 根目录，列出大于 1GB 的文件夹
du -h -d 1 ~/Library | grep '[0-9]G\t'
```

### 2.2 重点嫌疑对象深入排查
根据上一步的结果，通常有三个重点目录需要深挖：

**A. 容器与沙盒 (Containers)**
通常包含：Docker 虚拟磁盘、微信/QQ 聊天图片。
```bash
du -h -d 1 ~/Library/Containers | grep '[0-9]G\t'
```

**B. 应用支持 (Application Support)**
通常包含：iOS 本地备份、飞书/钉钉缓存、IDE 索引。
```bash
du -h -d 1 ~/Library/"Application Support" | grep '[0-9]G\t'
```

**C. 缓存目录 (Caches)**
通常包含：浏览器缓存、包管理器缓存 (yarn/pip)。
```bash
du -h -d 1 ~/Library/Caches | grep '[0-9]G\t'
```

## 3. 常见 "偷空间" 的元凶与处理方案

### 🐳 Docker (通常占用 30GB - 60GB)
* **现象：** `~/Library/Containers/com.docker.docker` 极其巨大。
* **原理：** Docker 使用 `Docker.raw` 虚拟磁盘文件。该文件 **只涨不跌**，即使删除了镜像，macOS 上的文件大小也不会自动回收。
* **处理方案：**
    1.  打开 Docker Desktop -> `Settings` -> `Resources` -> `Disk image size`。
    2.  **方法 A (推荐)：** 将滑块调小 (如限制在 32GB)，点击 Apply。这会重置 Docker，删除所有镜像和容器，彻底回收空间。
    3.  **方法 B：** 定期运行 `docker system prune -a` (仅清理内部垃圾，不一定能缩小宿主机文件占用)。

### 📱 iOS 本地备份 (MobileSync)
* **位置：** `~/Library/Application Support/MobileSync/Backup`
* **处理：** 如果有 iCloud 备份，直接删除整个文件夹。单次可回收 50GB+。

### 💬 办公与聊天软件 (飞书/微信/QQ)
* **飞书 (LarkShell)：** 缓存极大。进入 `设置` -> `基本设置` -> `存储管理` -> `清理所有缓存`。
* **微信/QQ：** 使用客户端自带的 `存储空间管理` 清理缓存。**切勿直接删除文件夹，否则聊天记录会丢失。**

### 🌐 浏览器缓存 (Edge/Chrome)
* **位置：** `~/Library/Caches` 或 `Application Support` 下的 Google/Microsoft 目录。
* **处理：** 浏览器内 `Ctrl+Shift+Delete` -> 清除浏览数据 -> 勾选 `缓存的图片和文件`。

## 4. 开发者日常维护建议
1.  **限制 Docker 胃口：** 在设置里锁死 Disk Image Size (例如 32GB)，防止它无限制吃硬盘。
2.  **定期清理编译垃圾：**
    * Xcode: 清理 `~/Library/Developer/Xcode/DerivedData`
    * JetBrains: `File` -> `Invalidate Caches`
3.  **冷数据转移：** 将 `Documents` 下不常用的项目文档、视频素材移至 SD 卡 (JetDrive) 或 NAS。
